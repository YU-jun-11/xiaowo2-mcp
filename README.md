## 三步部署（约 8 分钟）

1. **建 Worker**：登录 [dash.cloudflare.com](https://dash.cloudflare.com) → `Workers & Pages` → `Create` → `Worker` → 起名（如 `xiaowo`）→ Deploy
2. **建 KV 并绑定**：`Storage & Databases` → `KV` → `Create namespace` → 回 Worker → `Settings` → `Bindings` → `Add` → **KV Namespace**，变量名必须填 **`NEST`**
3. **粘代码**：Worker → `Edit code` → 全选删掉 → 粘贴 `worker.js` → `Deploy`

拿到地址后浏览器打开，看到 **「小窝 MCP 服务运行中 ☕」** 就成功了：

```
https://你的worker名.你的子域.workers.dev
```

**完整步骤（含设密码、连网页、连 AI、报错排查）见 [`部署说明.md`](部署说明.md)。**

## 让网页连上服务（云同步）

1. 打开 `小窝_情侣空间.html` → 点右上角 **☁**
2. 填 **服务地址**（`https://...workers.dev`，**结尾不要带 `/mcp`**）和 **密码**
3. 点连接 →「已连接」；再点一次「把本机数据传上去」

两个人各自手机上填**同一地址 + 同一密码**，看到的就是同一份小窝。

## 接到 AI 客户端

| 项目     | 填什么                                      |
| ------ | ---------------------------------------- |
| 服务 URL | `https://你的worker名.你的子域.workers.dev/mcp` |
| 协议     | **HTTP**                                 |
| 登录方式   | **请求头**，内容 `Authorization: Bearer 你们的密码` |

**没有「注册」这一步**：第一次用某个密码访问，就自动为它开一个空小窝；同一个密码永远回到同一个小窝。

连上后应看到 **39 个工具**。

**代码补丁**：以前 AI 只能改数据，现在能改页面本身——

> 「首页那行天数再大一点、加个描边」  
> 「情绪日历那个圆的颜色换成 #ff8ac0」

AI 写一小段 CSS/JS 存到你们云端，**刷新网页就生效**，不用改文件、不用重新发。补丁只对你们的网页生效，写错也不会把页面搞崩（可以让 AI 先停用或删掉）。

## 隐私与边界

- 数据存在**部署者自己的** Cloudflare 账号里，作者不经手
- 所有接口（含照片）都必须带密钥；照片是私有链接，别人拿到也打不开
- 没有密钥的人访问 `/` 只能看到「服务运行中」，看不到任何人的数据
- 免费额度：KV 每天 1000 次写入、1GB 存储 —— 两个人日常用足够；图片建议单张 ≤ 2MB（网页会自动压到 900px 再传）
- 生理周期数据**只存本机**，不会上传
